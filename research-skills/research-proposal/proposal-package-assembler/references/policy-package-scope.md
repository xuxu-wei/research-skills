# Package Scope Policy

## Purpose
Define what to include based on user request and workflow outputs.

## Scope Types

### Proposal Only
Include final proposal file, minimal status summary, and next steps.

### Proposal + Review Materials
Include readiness report, latest evaluation report, revision history, and unresolved issues.

### Proposal + Proposal Review Panel
Include panel summary and individual reviewer summaries or paths.

### Proposal + SAP
Only include SAP materials if the user explicitly requested SAP, SAP review, protocol/SAP output, or a target output requiring SAP.

### Partial Package
Use when required materials are missing. Clearly list missing inputs and limitations.

## Rule
Do not expand scope silently. When uncertain, assemble the narrowest responsible package and mark excluded materials.
