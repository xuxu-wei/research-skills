# Endpoint-Analysis Alignment Rules

## Purpose
Ensure the SAP analysis plan matches the research question, endpoint or metric, data structure, and preflight findings.

## Alignment checks
- The primary endpoint or metric must map directly to the primary research question or objective.
- The primary estimand or analysis target must state population, endpoint, exposure/comparator or predictor, time horizon, intercurrent event handling when relevant, and summary measure.
- The analysis population must be compatible with the target population and available data.
- Exposure, intervention, predictor, comparator, or grouping variables must be defined before model selection.
- The primary analysis must estimate or test what the proposal claims it will address.
- Covariate adjustment must be justified by the design, causal structure, prediction objective, or domain requirements.
- Secondary analyses must not replace or obscure the primary analysis.
- Post hoc and exploratory analyses must not be used to support confirmatory claims.
- Sensitivity analyses should address the main assumptions, not add unrelated analyses.

## Common failures
- Endpoint is clinically or scientifically meaningful but not measured in available data.
- Metric is defined verbally but not computable.
- Primary model does not correspond to outcome type or data structure.
- Analysis population differs from the proposal without explanation.
- Adjustment strategy is generic and not connected to bias, confounding, precision, or prediction requirements.
- Prespecified hypotheses are missing but the SAP uses confirmatory language.
- Exploratory or data-driven findings are written as hypothesis tests without exploratory labeling.
