# Reporting Standards Item Libraries

This directory is reserved for compact item libraries used by `article-context-builder` and downstream reporting checklist mapping.

## Current Coverage

Use `../reporting-standard-mapping.md` as the selection source of truth. When adding a standard-specific item library, keep it compact and name it after the standard, for example:

- `consort.md`
- `strobe.md`
- `prisma.md`
- `tripod.md`
- `stard.md`
- `arrive.md`
- `coreq.md`
- `cheers.md`
- `squire.md`
- `care.md`

Item libraries should list required manuscript locations and critical items that block submission when absent.
