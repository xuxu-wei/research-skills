# Revision Mode Routing

| Issue | Mode | Round? |
|---|---|---|
| Clarity/flow | textual_revision | yes |
| Section order | structural_revision | yes |
| Evidence link missing | evidence_relinking | no if no text changes |
| Checklist item missing | reporting_completion | no if no text changes |
| Overclaim | claim_downscaling | yes |
| Methods detail missing | methods_detailing | yes |
| Journal mismatch | journal_retargeting | yes |
| Language gate failure | language_polishing | no |
| Reanalysis needed | analysis_required | stop |
| Study design flaw | study_redesign_required | stop |

Entry strategies are `enter_manuscript`, `response_only`, and `decline`.
