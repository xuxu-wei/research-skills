# Supplementary Compliance Guide

## Checks

- Determine whether supplementary material is required from the Supplementary Index, main-text references, reporting guideline, or journal policy.
- Item count within journal limit.
- File format matches journal specification.
- Main text cross-references all supplementary items.
- Supplementary references handled according to journal policy.
- Data availability statement present.
- Code availability statement present when applicable.
- Missing supplementary items are listed, not fabricated.

If no supplementary item is planned, cited, or required, absence of a supplementary file is valid. If supplementary material is required and missing, block packaging until the missing item is provided or the requirement is removed from the blueprint/manuscript.

If journal limits are not verified, cap package status at `ready_for_author_check`.
