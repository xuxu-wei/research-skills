# research-article package naming

The package name is `research-article`. Individual skills intentionally use the shorter `article-*` prefix, for example `article-orchestrator`, `article-drafter`, and `article-evaluator`.

Do not rename these skills to `research-article-*`; downstream references and package metadata rely on the shorter prefix.
