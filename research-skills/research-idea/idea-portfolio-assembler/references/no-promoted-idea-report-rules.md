# No-Promoted-Idea Report Rules

Use this when no idea is suitable for PI portfolio promotion.

## Required Content

- stop reason;
- main bottlenecks;
- closest candidates, if any;
- failed gates or fatal flaws;
- evidence or preflight limitations;
- repair options;
- questions or decisions needed from PI/user.

## Allowed Stop Reasons

- no idea passed hard gates;
- evaluation failed or was invalid;
- evidence insufficient;
- preflight failed;
- core user context missing;
- ideas too duplicative or low-value.

## Boundary

Do not force a positive recommendation. A no-promoted report is a valid final output.
