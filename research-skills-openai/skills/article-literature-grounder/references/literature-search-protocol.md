# Literature Search Protocol

## Minimum Search Record

Record database, query string, date searched, date range, inclusion logic, exclusion logic, and source priority.

## Database Guidance

- Biomedical/clinical: PubMed, Embase if available, Cochrane, guideline sites.
- Computer science/AI: arXiv, Semantic Scholar, ACM/IEEE if available.
- Multidisciplinary: Google Scholar or Crossref as supplementary discovery.
- Field-specific sources should be named explicitly.

## Query Rules

- Build at least one broad query and one precise query.
- Include population/problem, exposure/intervention, outcome, and method terms when applicable.
- Search competing terms and synonyms.
- Track seminal, recent, conflicting, review/guideline, and citation-prerequisite coverage separately.
