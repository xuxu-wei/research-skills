# rules-literature-integration

## Purpose

定义 proposal 中使用文献、evidence summary 和研究现状材料的规则。

## Evidence Use

- 优先使用用户提供的文献摘要、evidence summary、funding call 和 context brief。
- 如证据只支持部分结论，应限制 claim 的强度。
- 如证据不足，应标记为需要补充文献核查。
- 不得把一般趋势写成已证明的特定结论。
- 不得虚构参考文献。

## Background and Rationale

立项依据应说明：

- 研究意义；
- 国内外研究现状；
- 发展动态；
- 科学意义或应用前景；
- 主要知识缺口或实践需求。

若缺少文献支持，应保留章节并列出待补证据点。

## Reference List

若用户提供了参考文献或 evidence summary 中包含来源，应在参考文献栏目中列出。

若没有可核查文献，不得编造文献目录；应标记为“需补充主要参考文献”。
