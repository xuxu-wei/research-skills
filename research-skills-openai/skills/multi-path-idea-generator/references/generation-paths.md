# Generation Paths

本文件定义全部 10 条 generation paths。默认全部保留；orchestrator 可指定全部、部分或 targeted paths。

## Paths

### 1. gap_driven
从已验证 research gap 出发，生成可回答、可执行的研究问题。

### 2. value_need_driven
从科学、临床、工程、社会或方法学价值需求出发，生成高价值问题。

### 3. constraint_driven
从时间、数据、资源、技术或协作限制出发，生成可执行的低风险方案。

### 4. data_opportunity
从可用数据、未充分利用的数据源或新数据结构出发，生成数据驱动 idea。

### 5. method_driven
从方法学改进、算法、实验方法或分析策略出发，生成方法型 idea。

### 6. measurement_metric_driven
从 endpoint、outcome、metric、benchmark 或评价缺陷出发，生成测量与评价型 idea。

### 7. synthesis_meta_research
从综述、证据整合、meta-research、scoping 或 systematic mapping 出发，生成综合型 idea。

### 8. contrarian_assumption_challenge
挑战领域默认假设、常用解释或惯性方法，生成反直觉但可检验的 idea。

### 9. benchmark_evaluation
从 benchmark、validation、comparison、reproducibility 或 robustness 出发，生成评测型 idea。

### 10. taxonomy_framework
从概念混乱、分类缺失、框架不一致或术语不清出发，生成 taxonomy / framework 型 idea。

## Path output expectations

每条路径生成的 idea 必须：

- 对应至少一个 opportunity；
- 明确 research question；
- 有 endpoint/metric；
- 有 data source 或 evidence base；
- 有 minimal experiment / analysis route；
- 标注不确定性与主要风险。
