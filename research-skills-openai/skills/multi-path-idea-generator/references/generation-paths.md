# Optional Generation Lenses

Load this reference only after the orchestrator assigns a generation or repair
lens. These lenses are optional; never run all of them by default.

- `gap_driven`: answer a verified unresolved question.
- `value_need_driven`: target a defined scientific, practical, or method need.
- `constraint_driven`: design within binding time, access, resource, or skill limits.
- `data_opportunity`: use a documented, accessible data asset for a defensible question.
- `method_driven`: apply or extend a method where it creates a real contribution.
- `measurement_metric_driven`: repair an endpoint, metric, benchmark, or evaluation gap.
- `synthesis_meta_research`: integrate evidence when synthesis itself answers the question.
- `contrarian_assumption_challenge`: test a consequential, falsifiable field assumption.
- `benchmark_evaluation`: validate, compare, reproduce, or stress-test a system or finding.
- `taxonomy_framework`: resolve a consequential classification or conceptual inconsistency.

For focused optimization, use the smallest lens set that repairs the current
Idea. For bounded exploration, use only lenses that yield two or three
substantively distinct, evidence-supported identities. A lens is not a quota and
does not justify a weak direction.

Every output remains a complete dossier with a clear question, objectives,
data/evidence base, methods, evidence chains, expected outputs, feasibility,
risks, claim support, and references. The lens never substitutes for those
sections and never authorizes the generator to score or rank.
