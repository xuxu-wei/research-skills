# Duplicate and Identity Control

Load this reference when two candidate directions or versions appear to overlap.

## Same Idea

Treat artifacts as the same Idea when they retain the same primary question,
objective, study object, core data/evidence base, and unit of inference. Title,
audience, emphasis, or editorial packaging alone does not create a new Idea.
Keep one node and write a new complete dossier version only when content changes.

## Distinct Idea

A changed identity anchor requires `new_idea_required`. Do not silently revise,
auto-fork, or merge it into the current node. Only an explicit user-started
workflow may create a derived node and parent lineage.

Bounded exploration may create independent sibling nodes only for directions
authorized by the frozen routing decision. It must not invent parentage.

## Actions

- Keep the stronger complete representation when two drafts are equivalent.
- Record discarded duplicate pointers and a human-readable reason outside the dossier.
- Preserve legitimate differences and dissent; do not collapse distinct
  directions merely to reduce count.
- If overlap cannot be resolved without judging or combining Ideas, return the
  ambiguity to the orchestrator. The generator does not rank or merge.
