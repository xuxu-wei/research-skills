# IF>10 Evaluation Gate

当用户在 raw_research_input 中设定 `paper_target: "IF > 10"` 时，独立 evaluator 需在常规六维评价之外附加 IF>10 可行性评估。

## Gate Rules

- 此 gate 是 advisory（建议性），不影响六维 core hard gates（feasibility≥3, relevance≥3, clarity≥3, completion≥3）
- 但 evaluator 应在 recommendation 中明确标注：idea 是否满足 IF>10 目标、如不满足应如何调整
- 如果 idea 的 IF>10 可行性为 fail/borderline，evaluator 应给出具体的 journal tier downgrade 建议

## Evaluation Dimensions

| 维度 | 问题 |
|------|------|
| 研究问题重要性 | 是否达到 IF>10 期刊的"practice-changing / paradigm-shifting" 门槛？ |
| 证据/实证强度 | 纯仿真+少量实证是否足以支撑 IF>10？是否需要更广泛的真实数据验证？ |
| 受众广度 | 是方法学专精读者还是全科临床读者？IF>10 综合期刊要求后者 |
| 叙事竞争力 | "新方法" vs "解决了困扰领域多年的老问题"——后者对 IF>10 更有竞争力 |
| 发表先例 | 该期刊过去 3 年内是否发表过类似方法学论文？可以作为 precedent |

## 评级

- PASS: 有明确路径——标注具体目标期刊
- BORDERLINE: 有条件可行——标注前提条件
- FAIL: 1-1.5 年内不可行——标注障碍和降档期刊

## 投稿路径建议

当 IF>10 可行但不确定时，evaluator 应提供多级投稿路径（首选→次选→保底），含各级接受概率估计。
