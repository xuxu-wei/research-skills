# Chinese Literature Access Rules

Use this file when Chinese-language literature, CNKI, Wanfang, VIP, Baidu Scholar, or Chinese domestic journals may matter.

## Principles

- Do not treat access failure as evidence absence.
- Mark inaccessible Chinese literature as an evidence limitation.
- Prefer user-provided titles, PDFs, DOIs, CNKI identifiers, or citation lists when available.
- If mobile or alternative access routes are known from existing skills, the orchestrator may choose whether to use them.
- This skill does not implement CAPTCHA bypass.

## Suggested Routing

- PubMed, Semantic Scholar, arXiv, and CrossRef where relevant.
- User-provided Chinese sources.
- Chinese database access rules from existing repository references.
- `captcha-solver` only as reference for access limitations and possible orchestrator-level routing.

## Output

When Chinese literature may be missing, include missing source class, likely impact, affected claims, and user-provided material that would resolve the gap.
