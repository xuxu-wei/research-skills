# 标书：申请与实施准备程度

评价研究方案能否支持已明确的申请或实施用途，与[研究价值](research-value.md)和[科学依据充分程度](scientific-support.md)分别报告。计划尚无研究结果不是直接降分理由；按已有基础、拟定设计和现实实施条件判断。

| 分数 | 判断依据 |
| --- | --- |
| 1 | 核心目标或设计不能成立，需要重构 |
| 2 | 存在已确认的关键缺口，当前不足以支持预定申请或实施，但有具体修复路径 |
| 3 | 主体方案已形成，仍有影响判断的科学、资源或申请条件待专业确认 |
| 4 | 在已明确的申请用途下，科学论证、方法、资源安排及必要材料足以支持下一步 |
| 5 | 在充分准备基础上，关键可行性、依赖条件及风险应对获得有针对性的进一步支持 |

评分依据可包括问题与目标的联系、研究设计和信息量、分析及解释安排、招募或数据获取、人员专长、设备与合作、预算和时间、相互依赖的研究目标及备用方案。只核查对当前项目有实质作用的事项，不把机构声望当作可行性依据，也不强制所有项目增加预实验或模拟。

明确本次是申请前评阅、实施准备检查还是早期构想讨论。没有指定资助项目时，评价通用科学准备程度，将特定申请条件列为尚未核对；不据此虚构合规性、资助机会或附件要求。缺少决定性材料而无法评分时暂不评分，不能用中间等级代替未知。

用户提供正式资助评审要求时，按其适用范围和原始尺度评价，说明本项目框架用于哪些补充判断；不擅自将不同尺度换算或混为一个总分。期刊的送审和发表条件不用于判定资助或实施准备程度。

本五级标准为本项目拟议标准，需人工试评。概念上参考 [NIH 简化评审框架](https://grants.nih.gov/policy-and-compliance/policy-topics/peer-review/simplifying-review/framework)对问题重要性、严谨性、可行性及专长和资源的区分；NIH 使用自己的评分和充分性判断，本表不声称由其规定或验证。
