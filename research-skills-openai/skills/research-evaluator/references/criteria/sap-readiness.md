# 统计分析计划：分析可执行程度

评价能否依据计划正确完成目标分析，与[科学依据充分程度](scientific-support.md)分别报告。研究项目本身的价值需有研究背景才能另按[共同价值标准](research-value.md)判断，不把新颖性作为分析质量要求。

| 分数 | 判断依据 |
| --- | --- |
| 1 | 分析目标、设计或数据根本不匹配，需要重构 |
| 2 | 存在阻止正确分析的关键缺口，需要定向修复 |
| 3 | 主要分析路线已形成，关键分析决策或数据条件仍待确认 |
| 4 | 关键定义、方法、数据需求和必要应变安排明确，可以据此正确实施 |
| 5 | 在可执行基础上，关键假设、敏感性安排及实施风险获得有针对性的进一步核实 |

根据问题检查目标效应或其他待估量、分析人群、结局与时间窗口、比较方向、变量推导、数据可得性、模型、协变量、依赖结构、缺失、多重比较、敏感性分析，以及必要的诊断与应变安排。对结果可能影响重大的选择应有可实施的依据，避免由分析者按有利结果临时决定。

恰当的常规方法可以获得很高评价；复杂模型、方法创新、额外模拟或新实验均不是最高等级的统一前提。进一步核实可来自现有的数据说明、已有验证、针对性推导或与关键风险相称的检查。只列出将来要做的核实不等于已经完成。

只有计划而无背景时，尽可能评价分析逻辑、科学依据和可执行性，列明无法判断的项目价值或数据条件。材料缺失到无法作出有依据的判断时暂不评分；不能将未知数据条件直接判为已证实缺陷。高项目价值不能掩盖不可执行的分析计划。

本五级标准为本项目拟议标准，需人工试评。参考 [ICH E9(R1) 临床试验统计指南增补](https://www.ema.europa.eu/en/documents/scientific-guideline/ich-e9-r1-addendum-estimands-and-sensitivity-analysis-clinical-trials-guideline-statistical-principles-clinical-trials-step-5_en.pdf)关于研究目标、估计目标、分析方法与敏感性分析一致性的要求；该来源未规定本评分。其临床试验细则按研究类型使用，不将药物试验的全部要求机械推广到其他学科。
