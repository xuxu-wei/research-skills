# 共同研究价值标准

用于选题、标书、论文、论证、研究改进和具有充分研究背景的分析计划。评价对象是研究对知识、判断或实际任务的贡献；计划阶段注明结果和交付条件。评论与更正线索不强制使用本标准。

## 评分与计算

单项采用 1 至 5 的整数，不用零分或半分。价值项目的低分不表示数据无效，科学依据另行判断。不适用的贡献子项写“不适用”；缺少决定性材料时写“暂不评分”，列明缺口，不填低分或补出综合分。材料已足够、仅需专家判断时可给初步评分，写清待核实问题及其可能影响。

分别评价问题重要性、适用的贡献子项、对认识或行动的实际影响、复用与参考价值。最突出的贡献取适用贡献子项的最高分，并写明来自哪一项；实际影响和复用与参考价值分别报告，计算时只取较高的一项。多个贡献不能累加抬分。

**综合研究价值等于问题重要性、最突出的贡献，以及实际影响与复用价值中较高一项的平均数，保留两位小数。** 三项中任一不能确定时不计算；不以已知部分的均值代替。科学依据、准备程度、受众广度和价值持续性不参与该平均。

每项写具体依据，尤其是影响决定的高分应指向可核查的材料、后果或用途。综合分用于描述和同类比较，不设通用晋级、淘汰或投入门槛；期刊适配另用[编辑决策标准](editorial-decisions.md)。

## 问题重要性

重要性与新颖程度分别判断。小人群的重大需求也可以很重要，热门领域则仍需说明这个具体问题为何值得解决。

| 分数 | 判断依据 |
| --- | --- |
| 1 | 未说明值得解决的知识、决策或资源需求，解决后新增价值有限 |
| 2 | 需求真实，但必要性或后果较有限 |
| 3 | 对明确领域或人群有实质意义，知识、决策或资源缺口清楚 |
| 4 | 涉及重要未满足需求、显著疾病负担或关键科学与实践决策，解决缺口意义较大 |
| 5 | 涉及核心且后果重大的未决问题，可靠解决可显著影响一个领域或关键人群 |

## 对认识或行动的实际影响

影响可以体现在科学认识、证据解释、研究设计或实践选择，不要求立即改变临床实践。关注、争论与引用热度不直接等于实质影响。

| 分数 | 判断依据 |
| --- | --- |
| 1 | 看不出会怎样改变认知、判断或行动，主要重述已有信息 |
| 2 | 补充局部认识，但很少影响重要判断或行动 |
| 3 | 对一类明确问题带来有意义的澄清、验证、调整或指导 |
| 4 | 有具体可信的依据，能够显著影响重要判断、实践选择、研究设计或证据解释 |
| 5 | 有强而具体的依据，能够实质重塑重要领域或关键人群的认知、实践或研究方向 |

## 复用与参考价值

先解释谁会使用、完成什么任务，以及本项研究实际提供什么。一个重要任务的反复使用可以支持高评价；用途或用户数量本身不加分，窄受众也不自动限分。

| 分数 | 判断依据 |
| --- | --- |
| 1 | 未说明他人如何使用，或已有容易取得的等效内容而本项未增加实际用途 |
| 2 | 有用途，但仅增加有限便利或局部价值，实质依赖较弱 |
| 3 | 对明确用户群或经常出现的任务有实际用途，使用方式清楚 |
| 4 | 对多个实质任务，或一个经常出现的重要任务，有显著支持；使用场景、采用依据及交付条件可信 |
| 5 | 有充分材料支持成为反复依赖的关键资源、方法或核心参考；对多类重要用途或一类关键任务具有基础作用，采用、交付及必要维护条件可信 |

贡献子项及文体特有的复用依据按[研究与资源](research-and-resources.md)、[证据综合](evidence-synthesis.md)或[观点与论证](arguments.md)评价。常规研究方法可完全适合任务；方法创新较少不等于科学依据或分析计划质量较差。

## 受众与持续性

需要说明服务对象或编辑选稿优先级时单独记录以下两项。它们不改变综合研究价值，也不能单独满足送审条件。

| 分数 | 受众广度 | 价值持续性 |
| --- | --- | --- |
| 1 | 个别团队或极窄任务 | 短暂或一次性，很快失效或被替代 |
| 2 | 小型亚领域或单一特殊情境 | 主要在有限使用周期内有价值 |
| 3 | 明确专科、领域或稳定用户群 | 有理由在本领域正常研究周期内持续有用 |
| 4 | 多个相关领域、研究社区或应用场景 | 有具体理由支持跨多个研究周期使用 |
| 5 | 广泛跨领域或多个实践群体 | 有较强依据长期作为稳定参考或基础资源 |

可按需要以低、中、高或不确定说明预期引用及原因，不设引用数量门槛，也不以引用预期弥补科学缺陷。
