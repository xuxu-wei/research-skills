# 编辑与投稿咨询的判断标准

仅用于投稿咨询和编辑处理。承接编辑部提供的科学内容流程，经中文完整名称改写；具体来源和试评状态见[来源说明](../guidance/sources.md)。有明确期刊政策时核实其适用要求；未指定期刊时，将本标准说明为咨询所用参考框架，不冒称某刊政策。期刊条件不用于资助或分析执行的判断。

## 常规送审的价值条件

先按[共同价值标准](research-value.md)和适用文章类型完成评价。在[科学依据](scientific-support.md)允许有意义的专业评议、没有需先修复的关键缺口时，以下任一组价值条件支持建议送审：

- 问题重要性至少 3 分，实际影响与复用价值中较高的一项至少 4 分；不对贡献新颖程度另设最低分。说明具体影响或用途。
- 问题重要性至少 4 分，最突出的贡献至少 3 分，实际影响与复用价值中较高的一项至少 3 分。说明重要性、贡献与实际用途。

综合研究价值没有独立送审门槛。达到这些条件仍需按实际期刊的审核政策和选稿安排处理，不构成接受承诺。

## 例外复核

未达到常规条件时，以下情形可提请第二编辑或编辑会议复核：

- 问题重要性至少 3 分，最突出的贡献至少 4 分，实际影响与复用价值中较高的一项至少 3 分。具体解释贡献的用途，不单凭首次、最大或稀缺。
- 距常规条件只差一个相关评分档位，且编辑对具体依据存在评分分歧。核查分歧，不用平均分替代判断。
- 问题非常重要而受众或用途较窄，或符合期刊明确的特殊栏目任务。说明服务对象、价值及待核实事项。
- 主编认为标准遗漏关键学术价值。记录遗漏内容、理由、实际批准人和后续核实要求。

贡献达到最高等级但实际影响与复用价值均低，单凭这种组合不产生复核或送审资格。关键患者价值或明确栏目任务等独立理由仍可提出。例外不能豁免科学有效性，也不能代替补齐关键材料。区分建议申请、正在复核、已经批准和已经否决；没有实际记录不得声称获得批准。

## 可发表条件满足程度

以下五级用于说明指定材料或明确情景所处的位置，独立于研究价值和科学依据展示。先判断科学依据，再判断价值条件与真实复核结果。材料不足时暂不评分。

| 分数 | 条件和含义 |
| --- | --- |
| 1 | 科学依据充分程度为 1 或 2 分，当前不能直接支持送审；说明可定向修复、需重构还是无法修复 |
| 2 | 科学依据充分程度至少 3 分，但未满足常规价值条件，也没有待处理的适用例外复核；说明改进贡献或调整投稿定位的理由 |
| 3 | 科学依据充分程度至少 3 分，未满足常规价值条件，但符合例外复核情形且尚无批准结果；下一步由有权限的编辑复核 |
| 4 | 科学依据充分程度为 3 分，且满足常规价值条件或已有明确例外批准；值得进入适用评议，决定性科学问题仍待解决 |
| 5 | 科学依据充分程度至少 4 分，且满足常规价值条件或已有明确例外批准；达到接受所需的科学内容和价值条件，实际决定还需相应评议 |

这不是录用概率，也不是项目投入回报排名。已有初稿达到最高等级但尚未完成适用评议时，下一步仍为正式投稿及评议；未完成研究的高评分只是条件性预期，仍需成稿及后续评议。例外被否决后按实际结果重新判断，不沿用待批准或已批准的描述。

## 咨询的主要结论

每次咨询给一个主要建议，必要时附专业核查或编辑复核动作。完整名称直接用于报告，不附内部编号。

| 建议 | 适用情况及下一步 |
| --- | --- |
| 暂缓结论并补充评估 | 决定性材料不足、需要专门方法学判断，或例外复核未完成。说明所缺材料、核查问题和完成后要决定的事项 |
| 重构后重新评估 | 需要改变核心问题、基本比较、关键测量或主要证据获取路径。提出可行替代，形成新方案后重评 |
| 定向完善后复评 | 问题和基本设计成立，但有应先修复的关键缺口，可在同一研究框架内解决。列明必要工作、预期改变的评价及复评条件 |
| 建议正式投稿 | 已有结果和材料足以形成可评议稿件，可发表条件满足程度至少 4 分，且无须先补齐的关键材料。说明文章类型、贡献和提交材料；是否送审由正式流程决定 |
| 建议按现方案推进 | 研究尚未完成，现有方案有现实可实现的至少达到送审条件的情景，无决定性设计阻断，科学收益与投入相称。说明证据链、节点和不同结果下的条件 |
| 建议调整投稿定位 | 科学贡献成立或有合理实现路径，但现有及现实改进后的主要情景未满足拟投期刊价值条件，或不符合其明确内容安排。说明适合的受众、文体或定位 |
| 不建议按当前方向继续投入 | 在现实可行的改进范围内仍不能回答有意义的问题，或增量价值低而投入明显缺乏依据，且无可行定向修复或重构路径。说明科学与资源理由以及仍可使用的材料 |

采用顺序是先处理信息不足或判断未定，再判断是否需重构或定向修复；没有这些阻断时，按成熟度建议投稿或继续推进。主要障碍仅是期刊定位时建议调整定位。只有现实科学收益或可行性不足且无改善路径，才建议停止追加投入。未完成可选扩展不自动导致降级；只在理想结果下达到高评分也不自动支持继续投入。

## 情景量化的解释

有依据的联合情景权重须同时覆盖结果和必要证据条件，而非只覆盖效应方向；权重来自数据、模型或明确的专家假设，互斥且覆盖主要可能性，总和为一。无可说明依据时保留分情景评价，不强行平均。

预期研究价值按各情景的综合研究价值乘以相应权重后求和，保留两位小数。送审科学条件的达成预期为可发表条件满足程度至少 4 分的情景权重之和；接受所需科学内容条件的达成预期为该程度达到 5 分的情景权重之和。后两项只是给定假设下的条件达成预期，不是最终录用率；不得将等级直接换算成百分比。说明主观权重、关键不确定性和较不利情景。

## 初筛与修回的处理含义

初筛分别建议送审、提交编辑讨论、暂缓并补充或核查，或不送审。分别说明科学依据、材料缺口、价值或明确选稿安排，不能将这些原因混写。已证实且不可修复的核心缺陷不进入正常送审；明确可修复缺口先修复；材料足够但技术判断待核实可按价值条件进入专业评议。

修回后，只有最终主张得到支持、决定性问题实质解决、原有价值仍满足常规条件或真实批准的例外、关键用途条件得到核实，科学依据充分程度至少 4 分且适用评议已完成，才可提出接受建议。可修复的决定性问题继续修改或补评；不可修复的核心问题支持拒稿建议。新证据实质改变价值依据时重新评价，不因效应变小或不再显著直接否定价值，也不无说明提高修回稿的要求。
