# Final Package Rules

## Purpose
Define how to assemble a final proposal package without rewriting, re-evaluating, or concealing upstream findings.

## Required Principles
- Treat the final proposal file as the deliverable of record.
- Include supporting reports as linked or summarized evidence, not as replacements for the proposal.
- Preserve evaluator decisions, reviewer dissent, unresolved risks, and file lineage.
- Do not add new scientific claims, methods, outcomes, or feasibility assertions during assembly.

## Package Order
Recommended order:
1. Package summary
2. Final deliverables
3. Proposal file information
4. Readiness and evaluation status
5. Revision history
6. Proposal review summary
7. Optional SAP materials
8. Unresolved issues and risks
9. Next human review steps
10. Included materials list

## Prohibited Actions
- Rewriting the proposal.
- Changing evaluator decisions.
- Removing fatal flaws or unresolved issues.
- Merging reviewer disagreement into false consensus.
- Adding SAP materials unless requested or required by the user's target output.
