# Proposal Editorial Repair Policy

## Eligibility and isolation

Use this mode only after scientific and methodology revision is complete for the current proposal. Narrative and language assessments must run concurrently in fresh instances against the same frozen proposal and reader handoff.

The orchestrator owns inclusion, exclusion, and conflict decisions. The controller may read both sealed action sets only after receiving the approved included action IDs and decisions, and may use them only to preserve fields, deduplicate approved overlaps, order dependencies, and materialize the brief. It cannot add an action or resolve a conflict independently. The writer may not read either action set; give it only the normalized brief, current complete proposal, and protected-content register.

## Normalization

The orchestrator approves an action only when it is locatable, executable without a scientific choice, compatible with binding constraints, and has an observable acceptance criterion. The controller validates the approved list and returns any violation instead of changing inclusion. It may materialize approved overlaps as one action only while preserving every assessor type and finding ID, and may order only acyclic dependencies. Any unresolved conflict returns to the orchestrator; the controller never chooses between scientifically different meanings.

Editorial actions may change disclosure order, section transitions, terminology definition order, repetition, sentence/paragraph structure, and academically appropriate wording. They may not upgrade or alter novelty, feasibility, impact, methods, endpoints, estimands, evidence strength, claim strength, or substantive risk posture.

## Authoritative assumptions, feasibility, and risks

Protect the proposal's single authoritative `Assumptions, feasibility, and risks` location. Conditional methods assumptions occur once there. Remove duplicated limitations elsewhere unless a boundary directly advances the immediate logic and omission would distort the connected design choice; state such a local boundary directly, without a cross-reference pointer.

## Execution and freeze

Use one writer instance and one complete target proposal. Sequential section passes are allowed within that target. Before freeze, validate every included action against its acceptance criterion and record execution evidence. A blocked action remains unresolved; it cannot be marked executed because the prose changed nearby.

After freeze, run a fresh content-preservation check and fresh narrative/language reassessments. Scientific change or preservation failure returns to scientific evaluation. Editorial failure returns to a new bounded editorial round.
