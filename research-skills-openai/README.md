# Research Skills

An OpenAI-oriented, skills-only research plugin for Codex. It contains 14 skills covering research ideas, proposals, articles, Perspectives, improvements to existing studies, methodology, medical journal review, and statistical analysis plans.

The main task develops and revises the work; fresh reviewers assess its scientific content. General search, data access, and document handling use the tools available in the environment.
