人体开放复杂巨系统的研究概念提出由来已久，但目前仍缺乏可落地的代表性模型，能够较为完整地描述人体系统结构，并支撑进一步的系统功能研究与临床转化。

我准备以脓毒症为例构建复杂系统模型。这是一个分阶段工作，第一阶段整合已有文献、专家知识，建立复杂系统模型。特别是考虑不同节点之间可能存在反馈回路。节点/角色包括外部干预（输入）、临床指标（系统）、临床事件/结局（输出）。第二阶段利用公共数据库进行系统辨识/网络权重训练，进一步描绘系统结构。第三阶段：在第二阶段验证通过的基础上，第三阶段连接干预成分-靶点-临床指标-临床事件，并使用已有RCT数据进行系统辨识，然后进行模型外部验证和分析，包括系统动力学、系统演变特征、潜在调控靶点和措施等，如有必要，增加一部分动物实验验证候选干预措施对脓毒症的效果。

第二阶段成功建模的（候选）标准：（1）能预测患者是否、以及什么时候发生脓毒症；（2）能预测什么时候脓毒症系统状态的演化结果（死亡或恢复正常）；（3）给t时刻初始部分状态或序列，能补全未观测的其他状态；（4）给t时刻初始状态或者初始序列，能预测后续演化情况和结果。
