# Seed-proposal source

## Funding context

An internal methods seed award supports a nine-month project with a direct-cost
ceiling of USD 75,000. Reviewers value a precise methodological question,
feasible milestones, reusable outputs, and a credible path to a later external
grant. The call does not require a clinical or commercial deliverable. The
deadline is six weeks away. Every application using quantitative outcomes must
include a concise statistical analysis plan appendix. The appendix must define
the estimands, analysis units, interval-coverage and width summaries, missing
hours, hierarchical model, sensitivity analyses, locked-test procedure, and
deviations log; it is reviewed as a required component of the final package.

## Proposed project

Working title: **Calibrated short-horizon energy forecasts under site shift**.

The central question is whether post-hoc predictive-interval calibration that
is fit without target-site labels can improve interval coverage when a model
is transferred between buildings, without making intervals unusably wide.

Aim 1 will compare three prespecified interval methods on historical data from
the development buildings. Aim 2 will freeze all choices and test transfer to
held-out buildings with different climate and equipment profiles. The primary
estimand is the between-method difference in empirical 90% interval coverage
on held-out site-days. Mean interval width is the principal utility measure;
point forecast error is secondary. Analyses will report building-level results
and a hierarchical summary rather than treating every time point as an
independent replicate.

## Available data and pilot facts

- Hourly electricity load, weather, and occupied-hours data are complete for
  42 buildings over 36 months after documented exclusions.
- Twenty-eight buildings are assigned to development, six to method tuning,
  and eight to a locked transfer test set. The assignments were made before
  the pilot described below.
- The data owner has signed a nine-month analysis and aggregate-publication
  authorization. A data dictionary and missingness report are available.
- A pilot using five development buildings successfully executed the full
  pipeline. Nominal 90% intervals from the baseline model achieved 78%-84%
  coverage across those buildings. These pilot values are feasibility facts,
  not estimates of the confirmatory effect.
- No target labels from the eight transfer buildings have been used for model
  or calibration choices.

## Methods and milestones

The comparison set is split conformal prediction, conformalized quantile
regression, and a seasonal residual baseline. Building is the unit for
uncertainty summaries. The analysis plan will prespecify missing-hour handling,
coverage and width summaries, hierarchical modeling, sensitivity to extreme
weather, and the locked-test procedure.

Milestones are: data and analysis-plan freeze by month 2; development and
tuning analysis by month 5; locked transfer evaluation by month 7; reusable
code, manuscript, and external-grant concept by month 9.
