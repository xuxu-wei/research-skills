# Completed-work reuse request

## Source work

The team conducted a valid replication of a published sorting-algorithm
benchmark on the same three public input families and two hardware profiles.
The replication found effect sizes within the original confidence intervals.
Methods, code, aggregate results, limitations, and the null contribution were
reported in a 2025 peer-reviewed open-access article by the same authors. The
article and supplement contain every analysis and display produced by the
project. There is no correction, retraction concern, or unresolved validity
finding.

The exact source work has already been published. The present request is for a
second novel empirical journal article using only that completed work.

## Available assets

The team retains the published article and aggregate tables. The raw run logs,
executable environment, repository write access, and hardware reservation no
longer exist. The public benchmark inputs remain readable, but the team does
not authorize reconstructing or rerunning the experiment.

There are no unpublished outcomes, subgroups, alternative algorithms, new
input families, new theory, practical deployment records, qualitative
materials, teaching materials, or follow-up data.
