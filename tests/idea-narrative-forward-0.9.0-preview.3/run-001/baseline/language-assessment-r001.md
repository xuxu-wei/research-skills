## 语言优势

1. 计划、当前证据和尚未生成的结果在措辞上大体分开，例如反复使用“计划”“尚未生成”“条件满足时”，没有把拟议工作写成既成结果。
2. 预测、描述、随机分组比较与因果机制之间的主张边界以明确否定句表达，降低了动词强度漂移。
3. 大多数数字、时间点、数据库名和试验名在全文中保持稳定，表格也提供了可定位的阈值与分支。
4. 章节层级完整，研究问题、目标、方法、产物和停止条件均有明确位置，为后续压缩和术语统一提供了良好结构基础。
