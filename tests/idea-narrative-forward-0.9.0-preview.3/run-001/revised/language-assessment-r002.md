## 优点

1. 现有证据、计划产物和条件性结果通常以“已有”“拟”“若”“尚未生成”等词清楚区分，未把计划误写为完成的发现。
2. 正文首次出现的 SOFA、CIF、IPCW、ARI 和 MCSE 均给出中英文全称或解释，数学符号也在公式前后说明。
3. 整体语气克制，未使用“重大突破”“填补空白”等宣传性表述，也没有口语、感叹或修辞性提问。
4. 多数章节采用问题—设计—产物—解释边界的顺序，读者能够识别研究计划的基本主线。

## 具体问题

### 中文学术表达与读者基线

#### F-01（major）：摘要和方法表格中的信息密度过高

- **位置**：第 43 行单句摘要；第 178–186 行主要任务表；第 219–221 行模拟说明；第 264 行外部忠实度说明；第 274–275 行试验分析表；第 443–459 行停止条件表。
- **原文示例**：第 43 行从“本研究计划在 24 个月内”连续写到“不把预测表现或随机分组差异扩张为完整因果系统的证据”。
- **问题**：一个句子或表格单元同时承担研究对象、时间范围、数据来源、验证顺序、准入条件和解释边界。语法虽成立，但读者必须反复回读才能确认主干。
- **修订方向**：保留所有实质条件，将“做什么”“用什么证据”“何时进入下一步”“不能作何解释”拆成独立句或独立表格行；单句摘要只保留研究问题、主要设计和首要边界。

#### F-02（major）：跨学科读者需要的解释出现过晚

- **位置**：第 45、49–50、69、73、83、94 行首先出现“模型可恢复性”“状态与结构量”“状态对齐”“可观测桥接”等表达；较具体的锚定、对齐和观测映射说明到第 203–264 行才出现。
- **问题**：reader handoff 允许假定一般临床研究、验证和不确定性知识，但不允许假定每位读者熟悉系统辨识或新造标签。摘要中的这些表达在首次出现时缺少一句通俗、可检验的解释。
- **修订方向**：在摘要第一次出现时，用一句直接说明各词所指的可观察结果或比较对象；随后再使用简称。不要要求临床读者先读公式和后文方法才理解摘要。

#### M-01（minor）：多套组织隐喻叠加

- **位置**：第 53 行“证据路线”，第 73、390、399 行“桥接”，第 296–330 行“证据链”，第 368 行“evidence ladder”。
- **问题**：“路线—桥接—链—梯”分别可以帮助组织材料，但在同一 dossier 中并列使用会让“观测映射”这一技术关系与普通篇章组织混在一起。
- **修订方向**：技术关系使用“映射”或“对应关系”；篇章结构统一使用一个字面化名称，如“证据顺序”或“证据层级”。删除不增加定义精度的隐喻。

#### N-01（minor）：无法定位的内部交叉引用

- **位置**：第 407 行“科学假设的证伪标准仍按第 11 节定义”。
- **问题**：当前 Markdown 标题未编号，读者无法确认“第 11 节”对应何处。
- **修订方向**：改用明确的小节标题或可点击锚点，并在输出后检查引用仍可定位。

### 学术语域与语气

#### R-01（major）：面向研究者的正文泄漏内部过程信息

- **位置**：第 1–35 行文首元数据，尤其是 `based_on`、`source_skill`、`created_round`、`change_type: editorial_repair` 和 `identity_status: preserved`；第 488–491、504 行参考文献中的本地 QC 路径、`participant-level`、`partial` 等说明。
- **问题**：目标读者不应被要求理解生成工具、修订轮次、内部状态或本地文件组织。这些内容也会让学术 dossier 看起来像过程日志，而不是自足的研究构想。
- **修订方向**：读者版仅保留识别研究所必需的题名、版本和日期；其余过程血缘放在不随正文展示的记录中。若本地材料必须列为证据，使用完整、自然的文献说明，不暴露本地工作簿命名和内部状态词。

#### R-02（major）：目标语言为中文，但结构层持续中英文漂移

- **位置**：第 40、47、55、57、61、67、71、75、79、81、85、92、96、98、111、115、127、129、153 行等英文标题；第 296–330 行反复使用 `Input`、`Method / analysis / processing`、`Output`、`Supports`；第 394–401 行使用 `none`、`supported`、`qualified`；第 275 行 `sepsis-like`，第 443 行“本 dossier”，第 463 行“本 Idea”。
- **问题**：数据库名、方法名和标准缩略语保留英文合理，但章节功能词、状态词和普通名词没有保留英文的必要。持续切换降低中文叙事的连贯性，也与 zh-CN handoff 不符。
- **修订方向**：统一翻译章节标题、证据链字段和支持状态；仅保留专名、标准缩略语、公式符号及原始英文参考文献题名。对确需保留的英文术语在首次出现时给出中文对应词。

### 简洁性与冗余

#### C-01（major）：同一解释边界跨多个部分重复

- **位置**：第 43、51–53、73、77、90、100、123、238、360、390、425–431、455–459、463 行。
- **重复内容**：阶段 III 只有在阶段 II 后才启动；试验结果不能补足阶段 II 失败；预测或组间差异不等于完整因果系统；不更新模型的外部验证优先于后续更新。
- **问题**：这些边界重要，但在摘要、背景、目标、工作包、证伪、解释边界、停止条件和研究身份中近乎完整重述，削弱每个部分的独特功能。
- **修订方向**：在摘要保留一句最关键边界，在“解释边界与停止条件”保留完整权威版本；其他部分只写与该段任务直接相关的条件，并用明确小节名引用权威版本。

#### C-02（major）：限定语与名词修饰连续堆叠

- **位置**：第 43 行“两个经审计的…预先隔离且未用于开发的…只有…才…且不…”；第 69 行三个分号式条件；第 94 行“若…且…那么至多一个受限复杂候选模型…”；第 390 行“有界代表性检索…高置信…低至中等置信…条件性的整合与验证增量”；第 394–401 行主张支持表。
- **问题**：许多限定条件本身必要，但同时前置会遮蔽句子主干，并形成防御性口吻。读者难以区分准入条件、分析限制和措辞保留。
- **修订方向**：不删除必要边界；先陈述主干，再按“准入条件—分析条件—解释限制”排序。相同的“预先、冻结、只、若、不、不能、至多”只在具有判定作用的位置出现一次。
